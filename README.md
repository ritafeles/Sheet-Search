# Sheet Search — Excel・CSV検索

## 起動
`Sheet-Search-1.2.0-win-x64.zip` を任意のフォルダにすべて展開し、`Sheet Search.exe` を起動してください。Windows x64用です。インストールやOffice、インターネット接続は不要です。実行ファイルだけを別の場所へ移動しないでください。

## 使い方
1. 「ファイルを開く」またはドラッグ＆ドロップで `.xlsx` / `.csv` を開きます。
2. 検索窓にキーワードを入力します。Ctrl+Kで検索窓に移動できます。スペース区切りは複数キーワードとなり、ANDは同じ行内のすべての語、ORはいずれかの語に一致します。完全一致はセル全体と各キーワードを比較します。
3. 左側で全シート／個別シート、検索対象列、列の条件を指定します。複数の列条件はANDです。条件で必要な列がないシートは除外理由が表示されます。
4. 結果の行をクリックすると元シートの前後3行が表示されます。Ctrl+クリックで複数選択し、「選択行をコピー」で見出し付きのタブ区切りとしてコピーできます。一度のコピーは最大10,000行です。
5. 「CSVに保存」は全検索結果をBOM付きUTF-8で出力します。先頭にシート名・元行番号が付き、異なるシートの列は見出しの和集合になります。元ファイルと同じパスには保存できません。

### 表示・コピー・並べ替え
- セルをクリックして選び、`Ctrl+C`を押すと、そのセルの文字だけをコピーできます。セルのダブルクリックでもコピーできます。下部の前後行表示でもセルをダブルクリックできます。
- セルを右クリックすると、文字に含まれる `http://` または `https://` のURLを一覧表示します。URLが複数ある場合は、開きたいURLを選択すると既定のブラウザで開きます。
- 左側の「表示する項目」で、列ごとに表示／非表示を切り替えられます。「すべて表示」「すべて非表示」も利用できます。非表示は画面表示だけに適用され、検索とCSV保存にはすべての列が含まれます。
- 表の列見出しをクリックすると、その列で昇順、もう一度クリックすると降順、3回目で元の順番に戻ります。数値と日付は値として比較し、空欄は末尾に配置します。
- 右上の月／太陽ボタンでダークモードを切り替えられます。選択は次回起動時も維持されます。

## 見出し・CSV設定
- 見出し行はシートごとに変更できます。番号を入力して欄の外をクリックしてください。0は見出しなしです。見出しより前の行は検索対象外です。
- 空の見出しはA・B・Cなどの列名、重複する見出しは連番付きになります。
- CSV設定ではUTF-8／CP932と、カンマ・タブ・セミコロン・縦棒の区切りを指定して再読み込みできます。自動判定が合わない場合に使用してください。
- 数値条件は小数・負数・指数表記に対応します。桁区切りカンマや通貨記号は数値として解釈しません。日付条件はYYYY-MM-DDまたはYYYY/MM/DD形式を日単位で比較します。

## 制約
- 閲覧専用です。編集、数式の再計算、旧形式 `.xls`、パスワード付きExcel、複数ファイル横断検索、正規表現には対応しません。
- Excel数式は保存済みの値を表示します。値がない場合は空欄となり、警告を表示します。Excelの装飾や複雑な表示形式は再現しません。日付と単純なゼロ埋め形式に対応します。
- CSVのセル内改行は保持します。元行番号はCSVのレコード番号で、セル内改行による物理的な行数は数えません。空行は検索結果に表示しません。
- 検索中のキャンセルはデータを保持します。読み込みのキャンセル時はファイルを開き直してください。
- 10万行程度を想定しています。非常に多くの列や長いセル、巨大なExcelではメモリ消費と処理時間が増えます。
- 未署名のローカル配布版です。Windowsが発行元未確認と表示する場合があります。

## 開発
Node.js 22.12以降を使用します。
```
npm install
npm test
npm run benchmark
npm start
npm run package
```
Electronのメインプロセスがファイル選択と保存を管理し、Node Workerが解析・検索を担当します。React画面にはページ単位で結果を渡し、仮想スクロールで表示します。ソースは `src/` と `electron/`、検証は `tests/` にあります。
