# Sheet Search ブラウザ版

## 起動方法
`Sheet-Search-Browser.html` をダブルクリックし、Microsoft EdgeまたはGoogle Chromeで開いてください。実行ファイルではないため、Smart App Controlを無効にする必要はありません。

## 安全性とデータ処理
- 選択したExcel・CSVはブラウザ内だけで読み込みます。ファイル内容をサーバーへ送信しません。
- インターネット接続なしでも、HTMLを開いて検索・絞り込み・CSV保存ができます。
- セル内のURLを開く操作だけは、選択したWebサイトへ通常のブラウザ通信が発生します。

## 操作
「ファイルを開く」またはドラッグ＆ドロップで `.xlsx` / `.csv` を読み込みます。検索、列条件、列の表示・非表示、並べ替え、セルコピー、行コピー、CSV保存、ダークモード、セル内URLの右クリック表示に対応しています。

ブラウザの設定によってコピーやダウンロードの確認が表示される場合があります。CSV保存では、ブラウザの通常のダウンロード先へ保存されます。
